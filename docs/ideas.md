# 有望なアイディア集（部品を使う側の参考に）

持ち主の依頼（2026-10-21）: 有望そうなアイディアを集めて保存する。部品を使う側（SinWave-Tree・Metasequoia など）が参考にする。
状況: ◎ = 確かめて効いた、○ = 見積もりや一部の実験で有望、△ = 試し中・未確認。数字の正本は NOTES.md、部品の評価の一覧は docs/parts_review.md。
新しい案や結果が出たら、この表に足していく。

## 1. 確かめて効いたもの（そのまま使える）

| 状況 | アイディア | 根拠 | 使い方 |
|---|---|---|---|
| ◎ | 担当なしの学習で、足すだけの融合 | 画像: 2 技能 80.8 → 100%、4 技能でも 100%（実験10・12） | 技能ごとに光路を別々に学び、関係のない一般の入力には「担当なし」を答えさせる。融合は光（確率）を足すだけ |
| ◎ | 学習率を最後に 0 まで下げる（cosine） | 学習中の谷が消え、最後が一番良くなる。④ MNIST 88.5 → 95.7%（実験17） | どの光路の学習にも使う |
| ◎ | 数の種類ごとの学習率（④ 波紋の中心 ×10・幅 ×0.1） | MNIST 96.3%・Fashion 85.9%（実験18、画像の最良） | 波紋の板を使うとき |
| ◎ | 符号で読む（窓の明るさの模様と、クラスごとの符号の近さ） | 窓 16〜256 個で 1 クラス 1 窓と同等以上、語彙を窓の数に縛らない（実験22・42） | クラスが多いとき（単語 1024 クラスなど） |
| ◎ | 部品ごとの窓で、例を見せないクラスを当てる | 例 0 枚のクラスで 77〜82%（実験26） | 部品の組み合わせでクラスを定義するとき |
| ◎ | 4f 系（光学相関器）2 段 + 光の非線形 | 位置の検出 AUC 89 → 97、10 種類の同時検出 85%（実験28・30）、学習 20 秒 | 「どこに何があるか」。板が少なくハードで作りやすい |
| ◎ | 位置ごとの明るさを学習（直前の文字ほど明るく） | 文字 38.7 → 43.6%（実験33） | 文字列・単語列を入れるとき |
| ◎ | **小さな 2DTG に表を分担させ、バラバラに学習して足すだけで融合**（持ち主の方針） | 単語で、同じ板 128 枚の 1 本 32.7% → 16 個 × 8 枚 36.0%（GRU 36.9、3-gram 36.4）。担当外は 99.8% が「担当なし」で、足すだけ = 担当を選ぶのと同じ（実験58） | 直前の語で担当を分け、担当なしの学習。細かく分けるほど良い |
| ◎ | 光路はデータが少ないときに強い | 単語 2 万件で光路 27.3% > GRU 25.7%（GRU は覚えすぎ、実験57） | 少ないデータの技能、たくさんの小さな技能 |

## 2. 見積もりで有望（光路での確かめが続く）

| 状況 | アイディア（持ち主の案を含む） | 根拠 | 次の一手 |
|---|---|---|---|
| ○ | **2DT グレイン（2DTG）**: k 語先を当てる小さな学習器を並べて、確率を割り当てで足す（持ち主の案） | 数えた表で、各 2DTG に「直前の語 + k 語前の語」を見せると 37.1%（3-gram 36.4）、CE 3.24（3-gram 3.96）。光路では CE 3.68 → 3.52（実験53） | 1 つ 1 つの光路の容量が足りない → 分担（実験58） |
| ○ | **関連度で確率を掛け直す**（持ち主の案）: 内容語の確率の合計は変えず、内容語の中だけ話題の近さで並べ替える | 数えた表で、内容語の位置の正解率 11 → 13〜22%、全体 CE 3.48 → 3.43。全部の語に掛けると機能語の予測を押しのける | 光の関連度グレイン（50 語の袋を 1 本の光で）は学べなかった（実験54）。袋を小さく、または注意の形に |
| ○ | **差分で関係を表す**（持ち主の案、王 − 女王 = 亭主 − 女房） | 数えた表のベクトルで 男 → 女 = 父 → 母、父 → 母 = 息子 → 娘 が 1 位。33 万語では弱い | 差分は板ではなく出口の符号の側で扱う（画像の実験09 で板への差分の足し算は壊れた） |
| ○ | **出口の模様を 2 次元フーリエ係数（縦 sin・横 cos の分離形）で持つ**（持ち主の案） | フーリエは足し算と内積を保つ（パーセバル）ので、差分も近さも少数の係数で計算できる。レンズの後の窓はもともとフーリエ係数 | 関連度・差分の計算を係数で |
| △ | **厚いホログラムに近づける**（持ち主のホログラムの問いから） | 入力の語 = 光の向き = 角度多重ホログラム。薄い板は角度を変えても図柄がずれるだけ。板を重ねるほど伸びる（実験55・56）のと合う | 実験59（板の間隔と枚数） |
| △ | **使われ方の近い語を近い光の向きに並べる**（持ち主の「差分・関連性の補完」の見立て） | 光路は近い入力に近い答えを返す（滑らか）。今の並べ方はでたらめで、その滑らかさが混線に使われている | 実験60。効けば、向きそのものを学習させる |
| △ | **光の注意（attention）**（持ち主の案、トランスフォーマーのような仕組み） | 注意 = 問いと鍵の近さ（関連度）で前の語を足し合わせる。近さは光の模様の重なりで、4f 系が一度に計算できる | 光路が直前 2 語しか使えない弱点を、離れた語を関連度で拾って補う |

## 3. ハードで速くなるもの（専用の光学ハード向き、docs/parts_review.md）

- 回折・レンズ・照明の数・窓の数は、ハードでは計算が増えない。GPU では照明の数だけ遅くなる tilt 照明（画像の形 70.6 → 79.9%、実験04）も、ハードではただ。
- 精度・雑音には強い（位相 4 ビットで 97.6%）。組み立てには極端に弱い（1 画素のずれでほぼ偶然、実験05）→ 板の少ない形（4f 系）か、1 つの部品にまとめて作る形。

## 4. 試して効かなかったもの（同じ道を避けるために）

| アイディア | 結果 |
|---|---|
| 1 次元で効いた照明の工夫（tilt・アダマール・重み付き・非コヒーレント光）、参照波（言語） | どれも +0.2〜0.8 点、ばらつきの範囲（実験51） |
| 光の記憶（2 次元）、鏡の往復、短冊形、入れ方の工夫 6 通り、位置ごとの色 | どれも 47% 前後か悪化（実験34・39・40・48・50） |
| 板の間に光の非線形（言語）、文字を板として掛け算で通す | 悪化・学習できない（実験36・45） |
| 場を大きくする（64 → 128） | 同じ板の枚数なら +0.3〜0.6 点、メモリ 4 倍（実験56） |
| 1 本の光路への差分の足し算（θ0 + ΔA + ΔB） | 2 次元では壊れる（実験09） |
| 親から子の木の作り方の違い | 差なし（実験20・25） |
