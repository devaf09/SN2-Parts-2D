# 2 次元で言語（LLM のようなもの）を目指す案（2026-10-20、持ち主の確認待ち）

持ち主の依頼（2026-10-20）: 1 次元ではあまりうまくいかなかったが、2 次元で LLM っぽいものを目指せないかを始めたい。

---

## 0. 1 次元（Sin-CNN2）で分かっていること

| 分かったこと | 数字 | 実験（Sin-CNN2） |
|---|---|---|
| 文字を一度に入れる方式は、文脈を伸ばしても良くならない | 48% で頭打ち | 27・30・32 |
| 1 文字ずつ入れ、前の出力の光を混ぜる「光の記憶」で、文脈が伸びるほど良くなる | 51.1% | 41 |
| 大きくすると伸び、3-gram を初めて上回る | 54.2%（3-gram 53.6、GRU 55.5） | 47・50 |
| データを増やすと GRU の方がよく伸び、差が開く。計算は GRU の約 350 倍 | | 50 |
| よく出る文字列をまとめる・部品の組で表す・うなり読みは、次の文字の予測には効かない | | 43〜46・52 |

1 次元の弱点（見立て）: (1) 光の場が 1 列なので「どの位置の・どの文字か」を 1 つの軸に詰め込むしかない。(2) 光の場に対して線形なので、「直前が A で、その前が B のとき」のような組み合わせ（非線形）を作るのが苦手。(3) 答えの窓が語彙の数だけ要る。

## 1. 2 次元で何が変わるか（画像認識の実験から）

| 画像で分かったこと | 言語での使い方 |
|---|---|
| 光学相関器（4f 系）は「どこにあっても同じ働き」= 畳み込み。間に光の非線形を入れると見分けが大きく強くなる（実験27〜30） | 文章の位置の方向に 4f 系を使えば、**畳み込みの言語モデル**（文字の並びの型を、どの位置でも同じように見つける）になる。非線形の段を重ねれば、組み合わせ（n-gram を超える文脈）を作れる |
| 板を通してから読むと、位置を向きに変えられる（実験01） | 縦 = 位置、横 = 文字 の 2 次元に並べれば、位置と文字を別の軸に持てる（1 次元の弱点 (1)） |
| 符号で読む: 窓の数がクラス数に縛られない（実験22・23） | 語彙が増えても窓を増やさずに済む（弱点 (3)）。新しい単語を学習なしで足す |
| 部品の窓で、例のないクラスを当てる（実験26） | 漢字を部品で表す（1 次元の実験40 は予測に効かなかったが、読み方が違う） |
| 担当なしの学習で、足すだけの融合が成り立つ（実験10・12） | 分野ごとの言語の技能（会話・技術文・料理…）を別々に学んで足す。木構造（Metasequoia） |

## 2. 案（段階）

**段階 T1: 文章を 2 次元の場に載せ、次の文字を当てる（1 次元と同じ課題で比べる）**
- 入力: 直前の n 文字（n = 8〜32）を、縦 = 位置（新しい文字ほど下）、横 = 文字の符号（各文字に決まった周波数の波、または 1 次元の文字コードの波）の 64 × 64 の場に載せる。
- 光路: (a) いまの板 ① 16 枚 + レンズ + 符号で読む、(b) 位置の方向の光学相関器（畳み込み）+ 非線形の段を 2〜3 段。
- 答え: 次の文字を符号で読む（窓 32〜64 個で語彙 64〜1000 字）。
- 比べる相手: n-gram（2・3・4）、GRU、小さな Transformer、1 次元の光の記憶（実験50 の 54.2%）。データは Sin-CNN2 が取得済みの CC-100 日本語の先頭 約 60 万字（Sin-CNN2/data/cc100_ja.txt、Common Crawl 由来。同じ持ち主のデータなので読み込んで使い、リポジトリには入れない。使ってよいかを確認したい）。
- 見るもの: 正解率と確信度（クロスエントロピー）、文脈を伸ばしたときに伸びるか、計算量（GRU の何倍か）。

**段階 T2: 光の記憶の 2 次元版**
- 前の出力の光（次の文字の予測の模様）を、場の別の行に戻して混ぜる（1 次元の実験41 の形）。縦の方向を「時間のテープ」として使い、古い文字は上へ流れていく。

**段階 T3: 技能の融合と木（Metasequoia につなぐ）**
- 分野ごとの技能を別々に学び、足すだけで融合する（担当なしの学習）。分野の判別・取消。

**段階 T4: 語彙を増やす**
- 符号で読む・部品（漢字の部首）で読むで、語彙を数千字に。学習なしの単語の追加。

## 3. 先に決めたいこと（持ち主の確認）

1. データ: Sin-CNN2 が取得済みの CC-100 日本語の先頭部分を使ってよいか（新しいダウンロードはしない）。
2. 最初の目標: 1 次元の最良（次の文字 54.2%、3-gram 53.6%）を、計算を大きく減らして上回ること、でよいか。
3. 進め方: T1 から順に。
