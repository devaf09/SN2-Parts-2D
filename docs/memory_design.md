# 記憶の設計メモ（持ち主の構想、2026-10-26〜）

持ち主の構想を書き留めて、実験の結果を足していく場所。**記憶の方法は今後増える予定**（持ち主の言葉: 「今後増える予定であることをわすれないでほしい」）。新しい方法の案が出たら、この表に足す。

## 前提（決まったこと）

- 持ち主の見方（2026-10-26）: AI には 2 種類ある。大量のデータから作る「人類の総集編のような高性能汎用大型 AI」と、「胸元で話を聞いてまとめたりする個人 AI」。**人の横にいる個人 AI では、記憶と処理は分けられない**。この記憶の研究は後者に向けたもの。

- 記憶に系列（一時 → 短期 → 中期 → 長期…）を持たせる。前処理として、記憶用の Grain を比率で融合する（実験87・88 で、4f 系の板への重ね書きで可能と確認）。
- **忘却はこのままで OK**（比率の小さい記憶ほど、記憶が増えると先に消える。実験87）。
- **一部の記憶は引き算できない（改ざんできない）方が望ましい可能性がある。融合が不可逆になってもそれはそれで OK**（2026-10-26）。
- 改善が必要な点（2026-10-26）:
  - 鍵が似ていると急に取り出せなくなる（実験88: 似ている度合い 0.5 で短期の記憶も 69%）
  - 同じ鍵に新旧の値があると短期（80%）の値が出る（実験88）。これを、記憶の方法によって変えられるようにしたい

## 長期記憶の方法（暫定 3 つ、今後増える）

| # | 名前 | 中身（持ち主の案） | 実験 |
|---|---|---|---|
| 1 | 繰り返し記憶 | 同じような記憶が前段（短期記憶）から何回も流れてきたら、記憶の強度を上げる。似た鍵で取り出せなくなるのを防ぐため、差分記憶法で: （前段からの記憶 − 現在の記憶）→ 対数 → 差分マップ → softmax（差分マップ + 現在の記憶）→ 融合。もしくはシンプルに「前段 0.8 + 現在 0.2 × 共通部分率」（現在の長期記憶の関連する部分を上げて融合） | 実験89 |
| 2 | 関連記憶 | 関連する部分の記憶を重要とする。前処理の差分や共通部分を関連度に置き換え、関係する記憶として重要度を上げて融合 | 実験89（簡単な形） |
| 3 | 重要度記憶 | 感情の機能、意識的に残したい記憶（パスワードなど）、重要人物のパターンなどで重みを上げる。1 + 2 の融合前マップから重要な部分の差分を取り出して強度を上げ、現在の記憶と融合（前段の値を上げて記憶する、対数的な差分） | 実験89（印を付けた記憶の重みを上げる形） |
| … | （今後増える） | | |

「記憶の強度」の言い方の候補: 定着度・記憶の重み（心理学では「記憶痕跡の強さ」、学習のモデルでは「重み」）。

## 実験の記録

- 実験87: 2 つの記憶 Grain を比率で 1 枚に重ね書きできる。明るさが比率どおりになり、どちらの記憶かを読める。薄い記憶ほど先に消える。
- 実験88: 単語の並びの鍵（拡散）は互いに似ず使える。確信度は短期ほど高い。同じ鍵の新旧は短期が勝つ。鍵が似ると急に取り出せない。
- 実験89: 短期 → 長期の移し方。**差分記憶法（鍵の共通部分を書くときも読むときも引く）で似た鍵の問題が消える**（似ている度合いによらず同じ成績）。**繰り返し記憶は「足りない分だけ書く」（すでに確信を持って取り出せる組は書く重みを 0.1 に）で全体 17 → 55%、新旧の食い違いで新しい値が出る 13 → 54%。** 単純に重みを上げる（3 倍）・関連で重くする・古い値を引く形は逆効果（強い記憶がほかを埋もれさせる）。重要の印（3 倍）は効く（77%）。
- 実験90・91: 案 1 の手順（対数の差分マップ）は作り直すと動き、そのままの 2 倍（17 → 34%）だが「足りない分だけ書く」（55%）には届かない。**値を実際の言葉（次の語）にすると、よく出る値に記憶が引っ張られ、512 組ではまれな値の組が 5% しか取り出せない**（値の頻度で割ると 92% に戻るが全体は下がる）。**板を 3 枚にして確信度で選ぶと全体 55 → 71%、新旧の食い違いで新しい値 65 → 90%。** 短期 → 中期 → 長期の系列は、重要・よく来る記憶は残るが全体は下がる（系列の作り方は要検討）。
