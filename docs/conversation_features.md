# 会話に要る機能の一覧（2026-10-22 作成、進み具合に合わせて更新）

持ち主の依頼（2026-10-22）: 会話する機能について、今後必要な機能の一覧を優先度つきで保存する。
持ち主の方針: 文書の予測より、チャット（会話）の方が個人的な目的に合う。データは青空文庫（著作権切れの小説の会話文）から始める。

優先度: **高** = 次に取りかかる・ほかの機能の土台、**中** = 土台ができたら、**低** = 先の話。
状況: ✓ = 部品・実験あり、△ = 案・見積もりのみ、× = まだない。

| 優先度 | 機能 | 中身 | 今ある部品・案 | 状況 |
|---|---|---|---|---|
| 高 | 長期・中期の記憶 | 昔の会話や覚えたことを保存して、必要なときに引き出す。中期 = その会話の中、長期 = 会話をまたいで | 光の記憶（効かなかった）、逆向きの連想 | △ |
| 高 | 文章の中の関連性 | 前の文・話題とのつながり。離れた語を拾う | 関連度（数えた表で内容語 +2〜11 点）、光の注意（案） | △ |
| 高 | 話し手・相手のモデル | 誰が話し、誰に話しているか。立場・関係・丁寧さ | 2DWIG（一人称、実験71）、2DWYG（二人称）、2DWTG（三人称） | △（2DWIG は実験中） |
| 高 | どう言うか（文にする） | 内容を、自分の口調・相手に合わせた丁寧さで文にする | 分担の 2DTG（次の語。GRU・3-gram 並み）＋ 話者の隠し味 | ✓（隠し味は △） |
| 高 | 文を作り続ける仕組み | 1 語ずつ選んで次に渡す。繰り返しを避ける。文を終える | なし（2DTG を順に回す外側の手順） | × |
| 高 | 分からないときの扱い | 自信がないとき「分からない」と言う、聞き返す | 担当なしの学習（担当外を 99.8% 見分ける、実験58）、確信度、「その他」を除く目安（実験68） | ✓ |
| 中 | 意図の理解 | 質問・お願い・感想・あいさつのどれか、何を求められているか | なし（分類器なら画像の分類と同じ形で作れる） | × |
| 中 | 会話の流れ（状態） | 話題、話の段階（あいさつ → 本題 → 締め）、順番 | 関連度（話題） | △ |
| 中 | 何を言うかを決める | 答える内容を選ぶ（中身の計画） | なし | × |
| 中 | 知識 | 事実（人・物・場所）を覚え、必要なときに引き出す | 逆向きの連想（穴埋め 21 → 34%、実験67）、部品の窓 | △ |
| 中 | 自分らしさの一貫性 | 一人称・口調・意見・覚えていることがぶれない | 2DWIG を自分の発言にも当てる | △ |
| 低 | 気持ち・場の空気 | 相手が喜んでいるか、困っているか | なし（Mutsumi の VISION にもある） | × |
| 低 | 良い・悪いの判断 | 言ってはいけないこと、相手を傷つけないこと | なし | × |

## メモ
- 光の部品にすぐ結び付くもの: 「分からないときの扱い」（担当なしの学習 = 自分の担当でない＝知らない）、「知識」（逆向きの連想で、答えから手がかりを引く）。
- 光の部品だけでは難しいもの: 「何を言うかを決める」「文を作り続ける仕組み」。部品を順につなぐ外側の手順（指揮役）が要る。
- 天井（2026-10-22 の整理）: 直前の数語だけを見る形は、その文脈で決まらない分を当てられない。天井を上げるには、長い文脈・話題・話者のような別の情報を入れる必要がある（高の 3 つ）。
