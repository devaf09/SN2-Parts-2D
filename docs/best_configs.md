## 画像

### 分類（MNIST・Fashion-MNIST）: ④ 減衰する波紋 128 個、波紋の数の種類ごとの学習率

| 項目 | 値 |
|---|---|
| 結果 | **MNIST 96.3%・Fashion-MNIST 85.9%**（3 seed、実験18）。小さな CNN は 98.1 / 87.6、ロジスティック回帰は 92.5 / 84.4 |
| 場 | 64 × 64。28 × 28 の画像を真ん中に振幅として載せる（位相で載せると悪化、実験02） |
| 光路 | 板 ④ 減衰する波紋（sin(k·r)/(k·r)）128 個 × 16 枚、初期の深さ 0.5 → 回折（角スペクトル法、間隔 64 画素）→ 明るさの平均を 1 に → レンズ → 窓 10 個 |
| 学習 | 5000 ステップ × 256 枚、Adam、学習率 0.01 → 0（cosine）。**波紋の中心の学習率 ×10、幅 ×0.1** |
| 学習する数 | 8203 |
| 時間 | 学習 約 210 秒（CNN 10〜19 秒） |
| 実行 | `python experiments/image/exp16_curve.py --data mnist --method sinc --n_ripples 128 --sinc_depth 0.5 --sched cosine --lr_center 10 --lr_width 0.1 --steps 5000` |
| 代わり | 板 ①（交点で掛け算）は 95.3 / 85.3% と少し下だが、学習が安定していて、どの誤差にも一番強い（実験05・17） |

### 技能の融合: 担当なしの学習で、足すだけ

| 項目 | 値 |
|---|---|
| 結果 | 2 技能で 80.8 → **100.0%**、4 技能でも 100.0%（同時学習 99.4、実験10・12）。取り消しは完全（差 0、実験07） |
| やり方 | 技能ごとに光路を別々に学ぶ。そのとき、どの技能とも関係ない一般の絵（ぼやけた塊・斑の模様）を「担当なし」として見せる。融合は光路の明るさを足すだけ |

### どこに何があるか: 4f 系（光学相関器）2 段 + 光の非線形

| 項目 | 値 |
|---|---|
| 結果 | 目標の数字の位置の検出 AUC 97、10 種類を同時に出して数字ごとに 85.3%（実験28・30） |
| 光路 | レンズ → 周波数の面に板 → レンズ（1 段）を 2 段、間で明るさを測って光を出し直す（非線形）。数字ごとに 1 本、色を分けて重ねる |
| 時間 | 学習 20 秒前後（板 16 枚の約 1/8）。板が少なく、ハードで一番作りやすい |

## 言語

### 文字（直前 8 文字 → 次の文字、64 クラス）: 分担の 2DTG を足すだけ

| 項目 | 値 |
|---|---|
| 結果 | **54.0%、CE 1.739**（16 個 × 板 8 枚、直前 4 文字、実験62）。64 個 × 2 枚、直前 3 文字なら 54.8% |
| 比べる | 光路 1 本の最良 50.1%（場 128・板 64、実験56）、GRU 53.3〜54.1%（CE 1.75〜1.80）、3-gram 53.7%、4-gram 55.4% |
| しくみ | 直前の文字の番号の余りで担当を 16 に分ける。各 2DTG は直前 4 文字を帯（縦 = 位置、横 = 文字ごとの向きの平面波）に入れ、位置ごとの明るさを学習、板 ① 8 枚 × 区画 16、レンズ、窓 256 個の符号読み（65 クラス = 64 + 担当なし） |
| 学習 | 各 2DTG を別々に 3000 ステップ（担当の文脈 70% + 担当外を「担当なし」30%）。訓練は全部（53 万件） |
| 融合 | 確率を (1 − p_担当なし) で重みをつけて足すだけ。担当外の 99.6〜100% が「担当なし」になり、担当を選ぶのと同じ結果 |
| 学習する数 | 34 万（大半は符号）。**光路 1 本の最良（4.9 万）の約 7 倍、GRU（17 万）の 2 倍。ただし光路 1 本に同じだけの符号（窓 4096）を持たせても 51.3% のまま（実験66）なので、分担の効果は本物。2DTG ごとに自分の符号を学ぶことが条件（固定すると 43.9%、実験64）** |
| 実行 | `python experiments/text/exp58_split.py --task char --m 4 --G 16 --layers 8 --max_train 600000` |

### 単語（形態素、直前 4 語 → 次の語、1024 クラス）

| 項目 | 値 |
|---|---|
| 結果 | **36.0〜36.4%**（分担の 2DTG 16 個 × 板 8〜16 枚、直前 2 語、実験58）。GRU 36.9%、3-gram 36.4% |
| 注意 | 符号（デジタルの重み、1025 × 256）が 2DTG ごとにあるので、学習する数は 427 万（光路 1 本は 33 万、GRU 76 万）。同じ学習する数の光路 1 本（窓 4096）は 33.3%（実験66）なので分担で +2.7 点。符号を固定すると 28.1%（実験64） |
| 光路 1 本 | 32.7%（板 128 枚、実験57）。2 万件の少ないデータでは光路 27.3% > GRU 25.7%（実験57） |
| 形態素解析 | MeCab（fugashi + unidic-lite） |

### 言語で分かったこと（部品を使う人へ）
- 1 本の光路は、全部の語（文字）が同じ板を共有するので、覚えられる対応表が小さい（実験55、図 docs/images/capacity.png）。大きくしても倍で +1 点。
- **表を分担させて足すだけ**にすると、同じ程度の重さで n-gram・GRU に並ぶ（文字）。光路を並べて足すのは、ハードではただ。
- 効かなかったもの: 照明の工夫・参照波（実験51）、光の記憶・鏡の往復・短冊（34・48・50）、板の間隔（59）、語の並べ方（60）、2DTG の木（61、CE だけ少し良い）、関連度グレイン（54）。
